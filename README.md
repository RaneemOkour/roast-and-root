# ☕ Roast & Root
> **Coffee · Nature · You**

A cinematic, nature-inspired specialty coffee website that tells the journey from bean to cup through quiet luxury, editorial typography, and immersive imagery.

---

## 🌿 The Concept
The core narrative follows the vertical journey of artisanal coffee:
**Bean → Roast → Brew → You**

---

## 🎨 Design System
- **Deep Forest Green:** `#3F4A2F`
- **Olive / Sage:** `#7D8752`
- **Warm Ivory:** `#F3EEE5`
- **Warm Charcoal:** `#25251F`
- **Muted Gold:** `#A58A5B`

---

## 📄 Site Architecture
1. **Home (`index.html`):** Hero narrative, vertical journey sidebar, and bean-to-cup roadmap.
2. **Menu (`pages/menu.html`):** The Bean, The Roast, The Brew, and The Root.
3. **About (`pages/about.html`):** Brand story, philosophy, and origin sourcing.
4. **Gallery (`pages/gallery.html`):** Masonry layout covering beans, roasting, space, and moments.
5. **Contact (`pages/contact.html`):** Store details, opening hours, and visit inquiries.
